# Ace-Combat7-PVE-Co-Op-mod
AC7 PVE Installation Guide (v0.2.0 — Test Version)
This is a PC (Steam) campaign co-op mode for 《ACE COMBAT 7: SKIES UNKNOWN》.
2–8 players can participate, and bugs may be found in some missions.
==============================
How It Works
After launching the launcher, press the Apply (Install/Patch) button to receive the patch.
In the [Settings] tab, you can configure various options for playing this mode. To apply options, you must press the Save button at the bottom. After applying options, you do not need to restart the game or hosting.
(Change setting values using the mouse wheel, by clicking the right arrow, or by double-clicking the settings field.)
In the [Play] tab, press [Launch After Backing Up Save] to start the game.
※ At this time, check that every item in the [Check Items] tab is displayed in green.
The host can create a session by pressing the [Host] button in the [Play] tab, then send invitations to Steam friends by pressing the [Steam Overlay] button.
※ Players who are not Steam friends can join when the host sends the session join code through another messenger.
Guests join by accepting the Steam invitation sent by the host or by pasting the session code into the join-code tab.
Immediately before playing, check that the usernames and number of users you invited are displayed in the [Roster/Friends] tab at the bottom.
When the host starts the desired mission, the mission is automatically loaded for guests.
※ Refer to the notes below.
==============================
Notes
!!Very Important!!
When playing PVE mode for the first time, the host must wait until the guests have completed sortie preparation.
If a mission is started during the first play before guests have completed sortie preparation, guests cannot enter the mission. Once guests' aircraft and weapon settings are saved after the first play, the last settings will be loaded automatically from then on. To change a guest's aircraft settings, the host must wait again.
(When configuring aircraft, you do not need to match the host's mission, difficulty, and so on.)
Some setting values may cause the session to crash or prevent smooth play. Configure them according to your PC specifications.
e.g.) Setting the enemy spawn count too high, or inviting more than four users, increases the load on the host PC.
If an invited user has made their game-play status private in Steam or has fixed their status as offline, their play cannot be recognized, which may make joining the session difficult.
Public lobbies are still being tested. Using Steam invitations/session codes for invitations is recommended.

This mod has safeguards designed in many ways, so I believe there will be no major problems with save/game files. However, backing up saves is recommended just in case.
The AC7 save location is as follows.
C:\UsersYourName\AppData\Local\BANDAI NAMCO Entertainment\ACE COMBAT 7\SaveGames

Occasionally, crashes may occur for reasons such as not following the stated process and notes, but the game files will not be affected.
